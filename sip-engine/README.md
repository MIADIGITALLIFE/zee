# SIP HTML Engine V1.0

SIP 是一个离线优先的 HTML 原型，用于检验配置管理、多体系交叉分析、主动任务模拟和 JSON 导入导出。

## 打开原型
打开 `index.html` 即可运行核心交互；不需要 AI 模型或外部 API。部分浏览器对本地文件下载/存储的限制可能有所不同。

## 当前能力
- 档案本地保存与载入
- 多体系权重归一化
- 可解释的关键词/权重候选分析
- 主动任务流程模拟
- JSON 导入与导出
- 会话内审计日志

## 重要边界
- 不连接 AI 模型。
- 不执行后台定时任务。
- 不向云端发送配置。
- 规则结果不是模型推理，也不证明存在主观意识。
- 本原型尚需真实浏览器测试；代码存在不等于验证通过。

详细规范见 [SPEC.md](SPEC.md)。
